# Solar System Sandbox — Unity 3D

A **Unity sandbox simulation** that allows users to create a solar system or an asteroid field, simulate gravitational motion (Newton + Verlet integration), and visualize gravitational fields in 2D or 3D.

---

## Overview
This project is an educational and experimental sandbox where the user can:
- create or procedurally generate celestial objects (planets, sun, asteroids),
- simulate their gravitational interactions in real time,
- visualize gravitational fields as vector fields or field lines.

The simulation uses the **Verlet integration algorithm** for stable orbital motion.

---

## Features
- **Physics simulation**
  - Newtonian gravitational forces.
  - Time evolution via **Verlet integration**.
- **Field visualization**
  - Vector field (2D or 3D grid).
  - Field lines emanating from a selectable source.
  - Grid fully configurable (size, density, position).
